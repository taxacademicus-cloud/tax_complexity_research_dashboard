불변 원문 Snapshot / Observation

source_snapshot

실제로 확보한 불변 원본 객체를 관리합니다. 동일 원문은 재사용하고 response_sha256으로 무결성을 검증하며 원본은 덮어쓰지 않습니다.

collection_observation

API 요청·수집이라는 사건을 관리합니다. 동일 Snapshot을 반복 관찰할 수 있고, 실패한 수집도 삭제하지 않고 기록하며 실패 시 snapshot_id는 NULL이 될 수 있습니다.

law_id법률 자체의 정체성을 식별. 국가법령정보 API의 법령 식별값 사용.
source_locator_idlaw_id + MST + 조문 구조정보를 이용해 특정 법령 버전의 조문 위치를 식별.
provision_id개정을 넘어 추적하는 논리적 규제단위의 영구 정체성.

snapshot_id판정의 근거가 된 불변 API 원문 객체를 식별.

· confidence는 0~1 범위로 통제
· 불확실한 계보는 강제 연결하지 않고 UNRESOLVED로 보존
